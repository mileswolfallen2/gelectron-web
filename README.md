# gelectron-web

A lightweight demo website for Gelectron — a small project showcasing web UI and performance benchmarks.

## Contents
- index.html — Main demo page
- docs.html — Documentation page
- style.css / docs.css — Stylesheets
- script.js — Demo scripts
- benchmarks.html / benchmarks.css — Performance comparison pages

## Quick start
1. Open [index.html](index.html) in your browser to view the demo.

2. For development, run a simple static file server in the project folder, e.g.:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000/
```

## Development
- Edit source files and refresh the browser. No build step is required.
